# Welcome to InstitutionKit

<div align="center">
  <h3>The Unified Cloud ERP for Educational Excellence</h3>
</div>

InstitutionKit is a complete **multi-campus school management ERP** built natively for WordPress. It transforms your WordPress installation into a powerful educational management platform capable of running single institutions or entire school networks.

---

## Why InstitutionKit?

<div class="grid cards" markdown>

-   :material-school:{ .lg .middle } **Multi-Campus Architecture**

    ---

    Manage unlimited campuses from a single WordPress installation. Each campus operates independently with its own students, staff, finances, and reporting — or view aggregated data across all campuses.

-   :material-shield-lock:{ .lg .middle } **Granular Role System**

    ---

    5 built-in roles with 62 custom capabilities. From Super Admin to Parent, every user sees exactly what they need — nothing more, nothing less.

-   :material-cash-multiple:{ .lg .middle } **Complete Financial Suite**

    ---

    Fee structures, automated invoicing, payment tracking, expense management, payroll processing, staff loans, budget planning — all in one system.

-   :material-file-document-multiple:{ .lg .middle } **Advanced Exam Module**

    ---

    Exam types, scheduling, result entry with verification workflow, report card generation (HTML & PDF), and comprehensive analytics.

</div>

---

## Who Is This For?

| User | What They Can Do |
|------|------------------|
| **Super Admin** | Full system control, all campuses, all settings |
| **Campus Admin** | Manage their campus — students, staff, fees, attendance |
| **Teacher** | Mark attendance, enter grades, assign homework, manage meetings |
| **Accountant / Finance** | Manage expenses, process payroll, track collections, set budgets |
| **Parent** | View child's grades, attendance, homework, invoices, and book meetings |

## Key Features at a Glance

| Module | Features |
|--------|----------|
| :material-account-group: **Student Management** | Admission, transfer, promotion, certificates, attendance |
| :material-briefcase: **Staff Management** | Contracts (fixed/hourly/per-lecture), attendance, salary components |
| :material-cash-register: **Fees & Invoices** | Fee types, fee structures, bulk assignment, invoice generation, payment tracking, reminders |
| :material-file-star: **Exams** | 7 exam categories, scheduling, result entry, verification, report cards, analytics |
| :material-calculator: **Payroll** | Auto-generation from attendance, tax calculation, loan deductions, payslips (PDF) |
| :material-chart-bar: **Gradebook** | Grading periods, grade scales, multi-period grade entry, performance tracking |
| :material-book-open: **Homework** | Assignments, submissions, grading, recurring homework |
| :material-calendar-clock: **Meetings** | Slot creation, parent booking, topics management, feedback |
| :material-certificate: **Certificates** | Leaving, character, achievement, employment certificates |
